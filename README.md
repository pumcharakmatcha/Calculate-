# 📋 งานของฉัน — แดชบอร์ดนัดหมายและแจ้งเตือนงาน

เว็บแอปส่วนตัวสำหรับ **จด / ดู / แจ้งเตือน** นัดหมาย งาน และอัปเดตการทำงาน
แก้ไขข้อมูลได้จากบนเว็บโดยตรง **ซิงค์ข้ามเครื่องด้วย GitHub Token**
และติดตั้งลงหน้าจอโฮมมือถือได้เหมือนแอปจริง (PWA)

ธีมขาว-น้ำเงินเรียบ สไตล์องค์กรญี่ปุ่น

## ฟีเจอร์

**บันทึกได้ 3 แบบ**
- 📅 **นัดหมาย** — มีวันเวลา + ตั้งเตือนล่วงหน้า
- ✅ **งาน** — มีกำหนดส่ง ติ๊กเสร็จได้
- 📝 **บันทึก** — จดอัปเดต สรุปประชุม ความคืบหน้า

**หน้าจอ**
- 🏠 **วันนี้** — สรุปตัวเลข (วันนี้ / 7 วันข้างหน้า / เลยกำหนด), รายการที่กำลังจะถึง, อัปเดตล่าสุด
- 📅 **ตาราง** — จัดกลุ่มตามวัน กรอง (ที่จะถึง / ทั้งหมด / เสร็จแล้ว) พร้อมช่องค้นหา
- 📝 **บันทึก** — ไทม์ไลน์บันทึกทั้งหมด ค้นหาได้
- ⚙️ **ตั้งค่า** — ซิงค์ การแจ้งเตือน ติดตั้งแอป สำรอง/กู้คืนข้อมูล

**อื่นๆ**
- 🔄 ซิงค์ข้ามเครื่องอัตโนมัติผ่าน GitHub Gist
- 🔔 แจ้งเตือนเด้งหน้าล็อกเมื่อถึงเวลา (ตั้งล่วงหน้าได้ 5 นาที – 1 วัน) + สั่น
- 🏷️ แท็ก และระดับความสำคัญ · 🔍 ค้นหาได้ทุกฟิลด์
- 💾 ทำงานออฟไลน์ได้ · ⬇️⬆️ ดาวน์โหลด/กู้คืนไฟล์สำรอง `.json`

## 🔄 ซิงค์ข้ามเครื่องด้วย Token

เว็บนี้ไม่มีเซิร์ฟเวอร์ จึงใช้ **GitHub Gist ส่วนตัวของคุณเองเป็นที่เก็บข้อมูล**
แปะ token ครั้งเดียว ที่เหลือระบบจัดการให้ทั้งหมด

### วิธีตั้งค่า

1. เปิด [หน้าสร้าง Token ของ GitHub](https://github.com/settings/tokens/new?scopes=gist&description=Work%20Dashboard)
   → ติ๊กเฉพาะสิทธิ์ **`gist`** อย่างเดียวเท่านั้น
2. เลือกวันหมดอายุ แล้วกด **Generate token**
3. คัดลอกโค้ดที่ขึ้นต้นด้วย `ghp_` มาวางในแอป → **ตั้งค่า › ซิงค์ข้อมูลข้ามเครื่อง**
4. **เครื่องอื่นใช้ token เดิม** ระบบจะค้นหา gist เจอเองอัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม

> ต้องเป็น **classic token** เท่านั้น เพราะ fine-grained token ยังไม่รองรับ gist

### การซิงค์ทำงานยังไง

- ซิงค์อัตโนมัติทุกครั้งที่แก้ข้อมูล (หน่วง 2.5 วินาที) ตอนเปิดแอป และตอนกลับมาออนไลน์
- รวมข้อมูลแบบ **last-write-wins ต่อรายการ** — แก้คนละเครื่องพร้อมกัน ตัวที่แก้ทีหลังชนะ
- การลบใช้ **tombstone** ทำให้ลบที่เครื่องหนึ่งแล้วหายที่ทุกเครื่อง (ล้างทิ้งอัตโนมัติหลัง 60 วัน)
- มีชิปบอกสถานะซิงค์มุมขวาบน: *กำลังซิงค์ / ซิงค์แล้ว / ซิงค์ไม่สำเร็จ*

### ความปลอดภัย

- Token เก็บใน `localStorage` ของเครื่องนั้นเท่านั้น **ไม่เคยถูกเขียนลง gist**
- ให้สิทธิ์แค่ `gist` แปลว่า token นี้แตะ repo หรือข้อมูลอื่นในบัญชีไม่ได้
- Gist ถูกสร้างเป็นแบบ **secret** (ไม่ขึ้นสาธารณะ)
- ถ้าใช้เครื่องสาธารณะ ให้กด **ตัดการเชื่อมต่อ** ทุกครั้งที่เลิกใช้
- ถ้า token หลุด ให้ไป revoke ที่ GitHub Settings ได้ทันที

## 📲 เพิ่มลงหน้าจอโฮม

**Chrome บน Android** — รองรับเต็มรูปแบบ
เปิดเว็บ → แตะเมนู **⋮** มุมขวาบน → **เพิ่มลงในหน้าจอหลัก** → **ติดตั้ง**
เปิดจากไอคอนแล้วจะได้แบบเต็มจอ ไม่มีแถบเบราว์เซอร์ เหมือนแอปที่โหลดจาก Play Store

**Safari บน iPhone** — แตะปุ่มแชร์ → **Add to Home Screen**

### เรื่องวิดเจ็ตบนหน้าล็อก
Android **ไม่เปิดให้เว็บแอปวางวิดเจ็ตบนหน้าล็อก** — ทำได้เฉพาะแอปที่เขียนด้วย Kotlin/Java
สิ่งที่เว็บแอปทำได้และใกล้เคียงที่สุดคือ:
- ไอคอนบนหน้าจอโฮม เปิดเต็มจอเหมือนแอป ✅
- **การแจ้งเตือนที่เด้งขึ้นบนหน้าล็อก** เมื่อถึงเวลานัดหมาย ✅

## ⚠️ ข้อจำกัดที่ควรรู้

- **การแจ้งเตือนไม่มีเซิร์ฟเวอร์ push** จึงทำงานเมื่อแอปเปิดอยู่หรือค้างอยู่เบื้องหลัง
  ถ้าปิดแอปทิ้งไว้นาน ระบบจะเก็บรายการที่เลยกำหนดไว้แจ้งทันทีที่เปิดแอปครั้งถัดไป
- **ถ้าไม่ต่อ token** ข้อมูลจะอยู่ในเครื่องนั้นเครื่องเดียว และหายถ้าล้างข้อมูลเบราว์เซอร์

## วิธีรัน

ต้องเสิร์ฟผ่าน **HTTPS** (เช่น GitHub Pages) ถึงจะติดตั้งเป็นแอปและใช้การแจ้งเตือนได้
เพราะ service worker กับ Notification API ต้องการ secure context

```bash
# ทดสอบในเครื่อง
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```
