# 🧮 เครื่องคิดเลข — ธีมขนมหวาน & อาหารคาว

เว็บเครื่องคิดเลขที่สลับธีมได้ 2 แบบ:

- 🍰 **ขนมหวาน** — โทนชมพูพาสเทลหวานๆ
- 🍜 **อาหารคาว** — โทนน้ำตาลเข้ม/ส้มอบอุ่น

## ฟีเจอร์
- บวก ลบ คูณ หาร และเปอร์เซ็นต์
- รองรับการพิมพ์จากคีย์บอร์ด (Enter = คำนวณ, Esc = ล้าง, Backspace = ลบ)
- จำธีมที่เลือกไว้ด้วย localStorage

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม
