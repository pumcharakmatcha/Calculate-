# 🕵️ INSIDER — เว็บเกมบอร์ดจับไส้ศึก

เว็บเกม **Insider** เล่นได้หลายเครื่องพร้อมกัน โดย**ไม่ต้องมีเซิร์ฟเวอร์**

## เล่นหลายเครื่องได้ยังไงโดยไม่มีเซิร์ฟเวอร์?
ทุกเครื่องคำนวณบทบาทเองจาก **รหัสห้องเดียวกัน** ด้วยตัวสุ่มแบบ deterministic
เมื่อทุกคนใส่รหัสห้อง + จำนวนผู้เล่นเท่ากัน และเลือกหมายเลขตัวเองไม่ซ้ำกัน
แต่ละโทรศัพท์จะได้คำลับและบทบาทที่สอดคล้องกันเองโดยอัตโนมัติ

## วิธีเล่น
1. ทุกคนเปิดเว็บนี้บนโทรศัพท์ของตัวเอง
2. ใส่ **รหัสห้องเดียวกัน** (คนหนึ่งกดสุ่มแล้วบอกเพื่อน) และเลือก **จำนวนผู้เล่นเท่ากัน**
3. แต่ละคนเลือก **หมายเลขผู้เล่นของตัวเองไม่ให้ซ้ำกัน**
4. แตะค้างที่การ์ดเพื่อดูบทบาทลับ (มาสเตอร์ / อินไซเดอร์ / ประชาชน)
5. ใช้หน้าจับเวลาช่วยกันถาม-ตอบเพื่อทายคำลับ แล้วโหวตหาอินไซเดอร์

## บทบาท
- 👑 **มาสเตอร์** — รู้คำลับ ตอบได้แค่ ใช่ / ไม่ใช่ / ไม่เกี่ยว
- 🕵️ **อินไซเดอร์** — รู้คำลับ แอบชี้นำกลุ่มโดยไม่ให้ถูกจับได้
- 🧑‍🤝‍🧑 **ประชาชน** — ไม่รู้คำลับ ช่วยกันทายและจับไส้ศึก

## วิธีใช้
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
